\# My Budget Tracker



\## Project Description



My Budget Tracker is a simple website for recording and viewing expenses. This project was continued from Week 2 and improved in Week 3 using CSS.



\## What I Improved in Week 3



\### Color Palette



I used a green, white, and light gray color palette to give the Budget Tracker a clean and consistent appearance.



\### Typography



I used Google Fonts in the CSS. Merriweather is used for headings, while Open Sans is used for the body text, labels, buttons, and table content.



\### Table and Form Styling



The expense form and table were improved with padding, borders, rounded corners, alternating table row colors, and consistent button styling. Hover and focus effects were also added.



\### CSS Box Model



I used margin, padding, borders, and border-radius to create separate card-style sections for the page heading, Add Expense form, and Expense Table.



\## Files



\* `index.html` - Contains the structure and content of the Budget Tracker.

\* `style.css` - Contains the visual design, colors, fonts, spacing, table styling, form styling, and card layouts.

\* `README.md` - Explains the project and the improvements made in Week 3.
